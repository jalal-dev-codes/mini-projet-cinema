🎬 Mini Projet Cinéma
📌 Présentation
Mini Projet Cinéma est un site web permettant aux utilisateurs de rechercher des films et de découvrir leurs informations.
Ce projet a été réalisé dans le cadre de mon apprentissage du développement web.
✨ Fonctionnalités

Recherche de films.
Affichage des résultats.
Consultation des informations détaillées d’un film.
Affichage des affiches de films.
Chargement de films supplémentaires.
Navigation entre les différentes pages.
💻 Technologies utilisées

HTML5
CSS3
JavaScript
API OMDb
📁 Organisation du projet
Le projet est organisé en plusieurs fichiers et dossiers afin de faciliter la maintenance et la compréhension du code.
🚀 Lancer le projet

Télécharger le projet.
Ouvrir le dossier avec Visual Studio Code.
Lancer le fichier index.html avec Live Server.
Profiter du site !
🎯 Objectif
Ce projet m’a permis de découvrir et de mettre en pratique les bases du développement web, notamment la création de pages web, le style CSS, la programmation JavaScript et l’utilisation d’une API.
